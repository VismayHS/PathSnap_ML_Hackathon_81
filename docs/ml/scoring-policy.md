# Provisional scoring policy: pathsnap-scoring-v0

The organizers describe observation-level accuracy but supply a chronological arc traversal rather than a GPS-row label file. Their official alignment and denominator policy remains unconfirmed. Every score under this policy is based on derived reference labels and must carry `policy_status=provisional`.

`src/evaluation/reference.py` reads references only for permitted offline development consumers and isolated post-prediction scoring. No inference, candidate, feature or decoder module imports it. `alignment.py` aligns valid GPS observations to ordered reference traversal occurrences, preserving repeated arcs and allowing forward skips between GPS samples. It never changes the reference or inserts reference arcs into inference candidates.

Alignment minimizes capped squared point-to-segment residual (20 m scale, residual capped at 100 m) plus a directional disagreement penalty of 2 times (1 minus cosine) when a GPS-only motion estimate is valid. A prefix-minimum dynamic program enforces monotone traversal occurrence order, with free start/end positions. Projected motion within one occurrence can move backward under noise; it does not create reverse roads. Forward skips are not time-constrained: this is a limitation, especially near loops and reference discontinuities. Direction and residual policy are fixed method choices, not learned features fitted on held-out labels. Low nearest-arc distance margin (<3 m) is retained as an ambiguity diagnostic, not excluded to inflate scores.

An observation is scorable if its raw coordinate/time passed cleaning and its aligned residual is at most 100 m. Invalid and reference-unscorable counts must be reported separately. A reference containing nonfinite/zero-length geometry currently makes alignment unavailable rather than silently dropping traversal occurrences. This is deliberately conservative and may require a documented later correction if real references contain such arcs.

The headline Top-1 Accuracy denominator is all scorable observations, including absent candidates and unmatched predictions as errors. Candidate misses are not removed. Per-trip Macro F1/precision/recall average over the union of true and predicted **road** IDs in that trip; unmatched is a missing prediction, not a new road class. Cross-trip aggregates are arithmetic means of per-trip metrics; never pool unrelated local arc IDs. A separate all-original-observation accounting count prevents hiding invalid/reference-unscorable cases.

Candidate miss rate is the fraction of scorable labels absent from the reference-free generated candidate sets. Conditional log loss is mean negative log normalized relevance assigned to the aligned arc **only when that arc is in the candidate set**, with the covered count given separately and misses reported alongside. Normalized relevance is not a calibrated probability. The API scorer uses server-private, reference-free evidence for candidate distributions; if absent it returns null with a reason.

Graph continuity and sequence metrics will be specified with their executed implementations before experiment publication. No metric values are claimed in this document.
