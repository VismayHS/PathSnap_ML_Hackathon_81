# Folium development maps: model hgb-hmm-v1

There are ten interactive maps, one per **student-test** trip. These are development data, so the reference route is shown. Each map has layers for raw GPS, the nearby road network, the reference route, the classifier-only prediction and the classifier + HMM prediction.

- Generated by `src/visualisation/folium/make_maps.py` from A's DevVisualisation export at commit `fe7e6322b925cc22455ad1aeb50fd15adffc25fe` (`results/hmm/hgb-hmm-v1/visualisation/`).
- To view with basemap tiles: `python3 -m http.server 8001 --directory maps/hgb-hmm-v1`, then open <http://localhost:8001/>. OpenStreetMap blocks tile requests from `file://`.
- To regenerate: `python -m src.visualisation.folium.make_maps --input results/hmm/hgb-hmm-v1/visualisation --output maps/hgb-hmm-v1`.
- These maps contain development reference geometry. They are never served by the API or copied into `ui/`.
